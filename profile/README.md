# Seedara

**AI video, image and audio generation in one place.** 140+ models from 19+ developers — Kling, Veo, Seedance, Nano Banana, GPT Image, FLUX, ElevenLabs, Suno and more — on one credit balance. You see the price before every run, and a failed run gives the credits back.

### Use it from your AI agent

Seedara runs a remote MCP server for Claude, ChatGPT, Cursor, VS Code and any MCP agent. No API keys: sign in to Seedara and press **Allow**.

```
https://seedara.ai/api/mcp
```

Setup for every client, tools and config examples: **[seedara-mcp](https://github.com/seedara-ai/seedara-mcp)** · [seedara.ai/mcp](https://seedara.ai/mcp)
